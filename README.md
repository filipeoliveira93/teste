# Idle ARPG (nome provisório)

Jogo idle com mecânicas de action RPG (Path of Exile, Diablo, Last Epoch) e runs de mapa com elementos roguelike.

- **Engine:** Godot 4.x (GDScript)
- **Documento de design:** [docs/GDD.md](docs/GDD.md)

> Repositório temporário — o conteúdo será migrado para o repositório definitivo.
