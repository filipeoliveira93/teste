# Árvore de passivas referencia apenas atributos, status e tags

A árvore de passivas é dividida em regiões de Força, Destreza e Inteligência, mais as zonas híbridas entre elas, e seus nós só podem citar atributos, status e tags de skill/arma — nunca um tipo de arma pelo nome. Cada tipo de arma declara suas tags, de modo que adicionar uma arma nova não exige alterar a estrutura da árvore. Rejeitamos o modelo comum de nós por arma ("+10% dano com Machado") porque ele obrigaria a redesenhar e rebalancear a árvore a cada arma nova.
